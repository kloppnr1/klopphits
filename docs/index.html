klopphits · koncept-UI

Kun stil og primær navigation — ingen funktioner. Hver sektion fylder hele skærmen med sit eget baggrundsbillede (i den rigtige app: dine billeder og Steam-covers). Controller: D-pad/stik, A = åbn, B = tilbage. Tastatur: piletaster, Enter, Esc. Touch: tryk for at vælge, tryk igen for at åbne, ‹ Hjem går tilbage.
